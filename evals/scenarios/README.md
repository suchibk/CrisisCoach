# Golden scenarios

`golden.json` version 1 contains fourteen executable scenarios mapped to the archived GoldenTestData script. The scenarios cover gates/driver priority, photo rejection/retry, neutral account handling, source context, injury, hostility/recovery, fire, denied/hypothetical danger, scuff capture/export/reopen, witness priority, Marcus unattended damage, controls, silence, and incident context.

The source script's T4/T5/T6/T9/T10/T13 expectations are adapted to the Python catalogue, honest evidence statuses, source requirements, and neutral output policy. T14 appearance is checked by the separate browser suite; real phone and microphone compatibility remain manual.

Schema: `crisis_coach.evaluation.runner.Suite`. Synthetic PNG provenance and SHA-256 hashes live in `crisis_coach/practice/fixtures/manifest.json`. Their fake verdicts are deterministic test labels, not an actual image-quality benchmark. Existing unit/integration tests separately cover corrupt/missing images, failed saves, duplicate inputs, provider failure, and photo-review limits.
